# Daniel Dreger — Portfolio

Personal portfolio site for **Daniel Dreger**, CMS web developer and data analyst.
A fast, self-contained static site (no build step) showcasing data, machine-learning,
visualization, and web projects.

🔗 **Live:** https://dandreger.com

## Tech

- HTML5, CSS3 (hand-written, no framework)
- Vanilla JavaScript (scroll reveal via `IntersectionObserver`)
- Google Fonts (Inter, Space Grotesk)
- Single-file, zero dependencies — deploys anywhere

## Run locally

Just open `index.html` in a browser. Or serve it:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploy

This site auto-deploys to [Netlify](https://www.netlify.com/) on every push to `main`.
